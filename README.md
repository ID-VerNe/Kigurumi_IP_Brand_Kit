# 专属 Kigurumi IP 视觉风格指南

这套极具辨识度的个人专属 IP 视觉系统，是从最初的 Kigurumi 形象逐步演化，并最终确立的“绝对居中对称”基准。
无论未来你是要做新的 App、个人网站，还是周边物料，只要遵循本指南中的“风格公式”，就能保证所有视觉资产的高度一致性。

---

## 🌟 一、 官方标准形象与核心特征
这是 IP 的核心视觉基准。它确立了 IP 的空间构成、色彩体系与五官比例。在进行任何衍生设计时，请严格遵守以下关于形状、颜色与位置的标定参数：

| 官方标准基础形象 | 核心特征规格说明 |
|:---:|:---|
| ![Base Logo](./00_Base_Reference.jpg) | **1. 渐变双马尾**<br>- **形状**：宽大、饱满的圆润水滴状下垂，无任何散乱发丝。<br>- **颜色**：上半部为主发色，下半部平滑渐变为粉色。<br>- **位置**：对称悬挂于头部两侧，发尾自然延伸至肩部以下。<br><br>**2. 红瞳**<br>- **形状**：绝对纯净、无高光、无睫毛的竖椭圆形。<br>- **颜色**：纯净宝石红。<br>- **位置**：位于脸颊中上部，两眼间距较宽，以营造幼态可爱感。<br><br>**3. 经典穿搭**<br>- **形状**：包裹肩部的厚实针织开衫与居中对称的胖胖领结。<br>- **颜色**：开衫为暖米白色，领结为深藏青色。<br>- **位置**：严丝合缝地占据画面下方区域。<br><br>**4. 颈部与五官细节**<br>- **嘴巴**：位于两眼下方正中央的极小的一段柔和弧线。<br>- **黑颈圈**：位于下巴正下方、衣领上方的纯黑色细窄长方形。 |

## 📐 三、 设计语言与画风
- **极简几何**：全图仅由少数几个大色块组成。拒绝任何多余的线条、描边、复杂的衣褶或阴影。
- **微拟物与柔和感**：抛弃绝对扁平的矢量感，采用带有极微弱厚度、边缘圆润饱满的处理方式。整体给人一种“软糯、治愈、犹如精致黏土手办”的触觉暗示。
- **绝对对称与极度居中**：人物从底部正中生出，绝对对称的构图赋予了 Logo 极强的权威感与稳定性，完美契合互联网产品的 Icon 设计规范。

## 📐 五、 非对称排版应用

| 右下角探头放大版 |
|:---:|
| ![Corner](./09_Banner_CornerPeek.jpg) |

**构图特点**：人物彻底偏离中心，从右下方切入，放大了角色在画布中的占比（约占 65%）。左上方留出大面积的纯色负空间。

## 🌟 六、 基础表情包矩阵
为增强 IP 的情感表达能力，在标准基础形象（薄荷绿背景、无道具）之上，延展出了以下 7 种核心情绪面部基准图。这些图片不仅可作为日常沟通的表情包、不同系统状态的提示插画，也是未来其他带道具扩展图的高级垫图。

| 1. 微笑 | 2. 俏皮 | 3. 开怀 | 4. 惊讶 |
|:---:|:---:|:---:|:---:|
| ![Smile](./10_Base_Smile.jpg) | ![Wink](./11_Base_Wink.jpg) | ![Happy](./12_Base_Happy.jpg) | ![Surprised](./13_Base_Surprised.jpg) |

| 5. 生气 | 6. 大哭 | 7. 迷糊 | |
|:---:|:---:|:---:|:---:|
| ![Angry](./14_Base_Angry.jpg) | ![Crying](./15_Base_Crying.jpg) | ![Dizzy](./16_Base_Dizzy.jpg) | |

- **微笑**：保持红瞳椭圆不变，嘴角微微上扬的温柔弧线。
- **俏皮**：左眼保持红瞳，右眼闭合成月牙，微张小嘴。（适合交互反馈）
- **开怀**：双眼闭合成 `^ ^` 形状，小张嘴。（适合成功、欢迎页面）
- **惊讶**：双眼圆睁，嘴巴变成一个小巧的 `o` 字形。（适合 404 或未找到页面）
- **生气**：微微皱眉 `\ /` 搭配下撇的小嘴。（适合禁止访问、报错拦截页面）
- **大哭**：紧闭双眼 `> <`，带有极简的蓝色泪珠流下。（适合内容删除、清空确认页面）
- **迷糊**：红瞳变成几何螺旋圈 `@ @`，波浪状的小嘴。（适合加载中、网络延迟页面）
