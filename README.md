# 专属 Kigurumi IP 视觉风格指南

经历了前几版的演化，现在终于把这套 Kigurumi 形象的“绝对居中对称”基准给定下来了。

以后不管是写新 App、搭个人网站，还是印周边，只要照着下面这些参数和垫图来出图，画风就不会跑偏。

---

## 🌟 一、 官方标准形象与核心特征
这是 IP 的核心视觉基准。它确立了 IP 的空间构成、色彩体系与五官比例。在进行任何衍生设计时，请严格遵守以下关于形状、颜色与位置的标定参数：

| 官方标准基础形象 | 核心特征规格说明 |
|:---:|:---|
| ![Base Logo](./assets/00_Base_Reference.jpg) | **1. 渐变双马尾**<br>- **形状**：宽大、饱满的圆润水滴状下垂，无任何散乱发丝。<br>- **颜色**：上半部为主发色，下半部平滑渐变为粉色。<br>- **位置**：对称悬挂于头部两侧，发尾自然延伸至肩部以下。<br><br>**2. 红瞳**<br>- **形状**：绝对纯净、无高光、无睫毛的竖椭圆形。<br>- **颜色**：纯净宝石红。<br>- **位置**：位于脸颊中上部，两眼间距较宽，以营造幼态可爱感。<br><br>**3. 经典穿搭**<br>- **形状**：包裹肩部的厚实针织开衫与居中对称的胖胖领结。<br>- **颜色**：开衫为暖米白色，领结为深藏青色。<br>- **位置**：严丝合缝地占据画面下方区域。<br><br>**4. 颈部与五官细节**<br>- **嘴巴**：位于两眼下方正中央的极小的一段柔和弧线。<br>- **黑颈圈**：位于下巴正下方、衣领上方的纯黑色细窄长方形。 |

## 📐 三、 设计语言与画风
- **极简几何**：全图仅由少数几个大色块组成。拒绝任何多余的线条、描边、复杂的衣褶或阴影。
- **微拟物与柔和感**：抛弃绝对扁平的矢量感，采用带有极微弱厚度、边缘圆润饱满的处理方式。整体给人一种“软糯、治愈、犹如精致黏土手办”的触觉暗示。
- **绝对对称与极度居中**：人物从底部正中生出，绝对对称的构图赋予了 Logo 极强的权威感与稳定性，完美契合互联网产品的 Icon 设计规范。

### 情绪使用场景说明
- **微笑 / 俏皮 / 开怀**：用于常规交互反馈、成功提示、欢迎页面。
- **惊讶 / 迷糊 / 流汗**：用于 404 页面、网络延迟、加载中、轻微报错。
- **生气 / 大哭 / 阴暗**：用于严重报错、禁止访问、清空删除确认、宕机提示。
- **星星眼 / 爱心 / 酷 / 吐舌 / 委屈**：用于打赏、点赞、完成任务、调皮彩蛋、恳求等高度情绪化的社交模块。
